# SOFYA

Jogo de plataforma 2D em desenvolvimento com Godot. Esta base de aprendizado tem uma personagem geométrica chamada Sofya, plataformas, colisões, câmera, comandos de movimentação, saída de fase e uma tela inicial simples.

Leia a documentação em [`docs/README.md`](docs/README.md) para começar.
